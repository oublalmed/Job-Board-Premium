Méthode

5 lectures indépendantes du code, en parallèle, une par domaine (candidat/évaluation/remédiation · CVthèque/recruteur/messagerie · facturation/admin/amorçage · non-fonctionnel/sécurité · frontend Next.js). Chaque ligne est notée à partir d'une preuve réelle — fichier et ligne, ou test correspondant — jamais d'une estimation à l'œil. Une note de 100 % exige à la fois une implémentation conforme et un test qui le prouve.

75–100 % — conforme, testé 50–74 % — partiel, écarts réels 25–49 % — ébauche seulement 0–24 % — aucune trace n/a — non applicable ou non vérifiable depuis le code ⚑ PIVOT retrait prévu par la décision du 3 août — désormais exécuté (offres/salaire supprimés) ✓ V0.3 exigence fermée depuis le 3 août (remédiation ou lot livré) — voir Mise à jour V0.3

Les moyennes par module sont des moyennes arithmétiques simples des exigences listées (Must + Should + Could), sans pondération. Les deux chiffres « cœur MVP » de la vue d'ensemble ne moyennent que les exigences classées Must par le CDC — c'est le nombre le plus représentatif de ce qui bloquerait réellement un lancement. ENF-02 (métrique frontend) et ENF-04/11 (non vérifiables depuis le code consulté) sont exclus des moyennes numériques.
